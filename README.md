# AI Text-to-Image Generator using Stable Diffusion

## 📌 Task

PRODIGY Internship – Task 02

## 🎯 Objective

To generate images from text prompts using a pre-trained Stable Diffusion model.

## 🛠️ Technologies Used

- Python
- PyTorch
- Hugging Face Diffusers
- Transformers
- Accelerate
- Stable Diffusion v1.5
- Google Colab
- NVIDIA T4 GPU

## 📖 Project Description

This project demonstrates text-to-image generation using a pre-trained Stable Diffusion model.

Different text prompts were provided to the model to generate images with different subjects, environments, and artistic styles.

## ⚙️ How It Works

1. Install the required Python libraries.
2. Check GPU availability.
3. Load the pre-trained Stable Diffusion v1.5 model.
4. Provide a text prompt.
5. Generate an image from the prompt.
6. Save the generated image.
7. Repeat the process with different prompts.

## 🧪 Experiments

### Experiment 1 – Robot Learning Python
Generated an image of a cute robot learning Python in a classroom.

### Experiment 2 – Futuristic City
Generated a futuristic city with flying cars, skyscrapers, and neon lights.

### Experiment 3 – Mountain Village
Generated a peaceful mountain village with forests, a river, and sunrise.

### Experiment 4 – Watercolor Robot
Generated a robot in a modern city using a watercolor artistic style.

### Experiment 5 – AI Healthcare Laboratory
Generated a futuristic healthcare laboratory featuring a doctor and an AI robot.

## 📊 Results

The Stable Diffusion model successfully generated images based on all five text prompts.

The experiments demonstrated how different prompts can produce different subjects, environments, and visual styles.
